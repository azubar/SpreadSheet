# 🚀 SpreadSheet — Зовнішня компонента 1С/BAS для конвертації MXL та PDF у зображення

[![Rust](https://img.shields.io/badge/Language-Rust-orange.svg?logo=rust)](https://www.rust-lang.org/)
[![Platform](https://img.shields.io/badge/Platform-Windows%20%7C%20Linux-blue.svg)](#)
[![Version](https://img.shields.io/badge/Version-0.7.3-green.svg)](https://github.com/azubar/SpreadSheet/releases)
[![License](https://img.shields.io/badge/License-MIT%20%7C%20SIL%20OFL-lightgrey.svg)](#ліцензії)

**SpreadSheet** — високопродуктивна зовнішня компонента за технологією **Native API** (`AddInNative`), написана на Rust. Вона призначена для швидкого перетворення файлів табличних документів `*.mxl` (1С 8.х / BAS) та документів `*.pdf` на растрові зображення **JPEG** або **PNG**.

Бібліотека повністю автономна, шрифти Liberation Sans / Serif / Mono та запасний DejaVu Sans вбудовано безпосередньо у бінарний файл, що дозволяє запускати компоненту на «безголових» (headless) серверах Linux та Windows Server без встановлених системних шрифтів.

---

## ✨ Основні можливості

* 📑 **Повний розбір MXL8 (1С 8.2 / 8.3 / BAS)**: текст комірок, шрифти (вага, нахил, підкреслення, закреслення), межі, об'єднання комірок, вирівнювання, перенесення, висоти рядків та ширини колонок.
* 🔢 **Значення комірок і форматні рядки 1С**: комірки зі значенням (число, дата, булево — як параметри макетів друкованих форм) виводяться за форматним рядком комірки (`ЧДЦ`, `ЧРД`, `ЧРГ`, `ЧГ`, `ЧН`, `ЧО`, `ЧС`, `ЧВН`, `ДФ`, `ДЛФ`, `ДП`, `БЛ`/`БИ`) — як `Формат()` у 1С.
* ↔️ **Вирівнювання «по ширині»** та **довільний кут тексту** (не лише 90°).
* 🔤 **Шрифти за назвою**: Arial/Tahoma та подібні → Liberation Sans, Times New Roman/Georgia → Liberation Serif, Courier New/Consolas → Liberation Mono (метрично сумісні); символи, яких немає в Liberation (✓, стрілки, математичні знаки), беруться із запасного шрифту DejaVu Sans.
* 📄 **Сторінки MXL**: `НомерСтраницы` для MXL виводить окрему сторінку за областю друку та явними розривами сторінок; `КоличествоСтраниц` повертає їх кількість (для MXL і PDF).
* 💾 **Вхід з `ДвоичныеДанные`**: методи `…ИзДанных` приймають документ (MXL або PDF) з пам'яті — без тимчасових файлів на сервері.
* 🎨 **Рендеринг кольорів та заливок**: підтримка довільних RGB кольорів, вертикальний текст (90°), 19 видів узорів заливки.
* 📦 **Вбудовані картинки та графічні об'єкти**: відображення картинок (PNG/JPEG, масштабування з фільтрацією) та фігур («надпис», «прямокутник»).
* 📋 **Пряма робота з Буфером Обміну (Clipboard)**: швидке копіювання зображення для вставки через `Ctrl+V`.
* 🛡️ **Безпечний рендеринг PDF через OS-Native API**:
  * **Windows**: використання WinRT API (`Windows.Data.Pdf`) через фоновий MTA-потік, що запобігає блокуванню файлів на диску та STA-блокуванням у клієнтських сесіях.
  * **Linux**: використання утиліти `pdftoppm` з автоматичним центруванням сторінок та гнучким налаштуванням полів і відступів.
* ⚡ **Автономність**: розмір скомпільованого файлу близько **7 МБ** (з них ~5 МБ — вбудовані шрифти).

## 🛠️ API компоненти

### Властивості

| Назва (Eng) | Назва (Укр/Рус) | Тип | Доступ | Опис |
|---|---|---|---|---|
| **`Version`** | `Версия` | `Строка` | Читання | Повертає поточну версію компоненти, наприклад `"0.7.3"`. |
| **`Quality`** | `Качество` | `Число` | Читання/Запис | Якість стиснення JPEG, від `1` до `100` (типово `90`). Для PNG ігнорується. |
| **`Scale`** | `Масштаб` | `Число` | Читання/Запис | Масштаб рендерингу у відсотках від вихідного документа, від `1` до `1000` (типово `100`). |
| **`PageNumber`** | `НомерСтраницы` | `Число` | Читання/Запис | Сторінка для конвертації (з `1`). PDF: якщо `0`, всі сторінки склеюються вертикально. MXL: якщо `0`, виводиться весь документ, інакше — сторінка за областю друку та розривами. |
| **`PdfDpi`** | `РазрешениеPDF` | `Число` | Читання/Запис | Роздільна здатність растеризації PDF, від `50` до `600` (типово `96`). Підсумкова роздільна здатність — `РазрешениеPDF × Масштаб / 100`. |
| **`PdfPageSpacing`**| `ИнтервалСтраницPDF`| `Число` | Читання/Запис | Вертикальний інтервал між сторінками PDF при склеюванні, від `0` до `200` (типово `10`). |
| **`ImageMargins`** | `ПоляКартинки` | `Число` | Читання/Запис | Зовнішні білі поля навколо підсумкового зображення у пікселях, від `0` до `500` (типово `0`). |
| **`MaxImageBytes`** | `МаксимальныйРазмерКартинки` | `Число` | Читання/Запис | Максимальний дозволений розмір результуючого файлу в байтах (типово `50 000 000` (50 МБ)). |
| **`PngCompression`** | `СжатиеPNG` | `Число` | Читання/Запис | Ступінь стиснення PNG: `0` — швидко, `1` — звичайно (типово), `2` — максимально. Для документів з текстом PNG зазвичай менший і чіткіший за JPEG. |
| **`PrintMode`** | `РежимПечати` | `Булево` | Читання/Запис | Режим «як при друку» для MXL: кожна сторінка — картинка аркуша (формат, орієнтація, поля, масштаб друку, автомасштаб, ч/б друк — з параметрів документа), поділ на сторінки за розміром аркуша та розривами. Типово `Ложь`. |
| **`PrintDpi`** | `РазрешениеПечати` | `Число` | Читання/Запис | Роздільна здатність аркуша в режимі друку, від `50` до `600` (типово `150`). |
| **`Grayscale`** | `ОттенкиСерого` | `Булево` | Читання/Запис | Вивід у відтінках сірого для будь-якого документа (PNG/JPEG одноканальні — файл менший). |
| **`ThrowErrors`** | `ВызыватьИсключения` | `Булево` | Читання/Запис | `Истина` (типово) — помилка генерує виняток; `Ложь` — метод повертає `Ложь`/порожні `ДвоичныеДанные`, а текст помилки — у `ОписаниеОшибки`. |
| **`LastError`** | `ОписаниеОшибки` | `Строка` | Читання | Текст помилки останнього виклику (порожній рядок при успіху). |

### Методи

* **`СохранитьКартинку(ПутьКФайлу, ПутьКартинки, ТипКартинки)`** / `SavePicture`  
  Конвертує вхідний файл (`*.mxl` або `*.pdf`) та зберігає результат на диск.  
  *Повертає:* `Истина` (`true`) у разі успіху.

* **`ПолучитьКартинку(ПутьКФайлу, ТипКартинки)`** / `GetPicture`  
  Конвертує вхідний файл та повертає байти зображення безпосередньо в 1С як `ДвоичныеДанные`.

* **`ПолучитьКартинкуВБуферОбмена(ПутьКФайлу, ТипКартинки)`** / `GetPictureToClipboard`  
  Конвертує вхідний файл та копіює зображення безпосередньо у системний буфер обміну. Працює лише в клієнтському інтерактивному сеансі.  
  *Повертає:* `Истина` (`true`) у разі успіху.

* **`СохранитьКартинкуИзДанных(Данные, ПутьКартинки, ТипКартинки)`** / `SavePictureFromData`,  
  **`ПолучитьКартинкуИзДанных(Данные, ТипКартинки)`** / `GetPictureFromData`,  
  **`ПолучитьКартинкуИзДанныхВБуферОбмена(Данные, ТипКартинки)`** / `GetPictureFromDataToClipboard`  
  Те самі методи, але документ (MXL або PDF) передається значенням `ДвоичныеДанные`, а не шляхом до файлу. Тип документа визначається за вмістом.

* **`КоличествоСтраниц(ПутьКФайлу)`** / `PageCount`, **`КоличествоСтраницИзДанных(Данные)`** / `PageCountFromData`  
  Повертає кількість сторінок документа: для PDF — сторінки файлу, для MXL — сторінки за областю друку та явними розривами, а в режимі друку — аркуші.

* **`СохранитьСтраницы(ПутьКФайлу, ШаблонИмени, ТипКартинки)`** / `SavePages`, **`СохранитьСтраницыИзДанных(Данные, ШаблонИмени, ТипКартинки)`** / `SavePagesFromData`  
  Зберігає кожну сторінку (аркуш у режимі друку, сторінку PDF) в окремий файл. `{N}` у шаблоні замінюється номером сторінки (`C:\out\стр_{N}.png`), без нього номер додається перед розширенням. *Повертає:* кількість збережених файлів.
