# Опис компоненти SpreadSheet

## Призначення

Компонента вирішує дві основні задачі:
1. Перетворити файл табличного документа `*.mxl` (1С:Підприємство 8.х / BAS) або документ `*.pdf` на растрове зображення (JPEG/PNG).
2. Записати результат у файл, повернути як двійкові дані або скопіювати напряму в буфер обміну (Clipboard) для швидкої вставки (`Ctrl+V`).

## Технологія

Компонента побудована за технологією **Native API** (`AddInNative`). Уся логіка написана мовою Rust:

| Шар | Реалізація |
|---|---|
| Розбір формату MXL | власний парсер (`spreadsheet/src/mxl_parser.rs`) |
| Рендеринг PDF | OS-Native API (WinRT `Windows.Data.Pdf` на Windows, `pdftoppm` на Linux) |
| Растеризація | [tiny-skia](https://crates.io/crates/tiny-skia) |
| Текст (для MXL) | [ab_glyph](https://crates.io/crates/ab_glyph) + вбудований шрифт Liberation Sans |
| Кодування JPEG/PNG | [image](https://crates.io/crates/image) |
| Буфер обміну | [arboard](https://crates.io/crates/arboard) |

Завдяки використанню нативних API операційної системи для PDF-файлів, компонента зберігає компактний розмір (2-4 МБ) та не потребує розгортання великих сторонніх бібліотек на кшталт Google PDFium.

## Обмеження

- **Буфер обміну**: працює тільки в інтерактивному сеансі користувача (на клієнтському робочому місці).
- **PDF на Linux**: вимагає встановленого пакета `poppler-utils` (`pdftoppm`).
- **Розмір зображення**: обмежено 65 500 px за кожною стороною, 250 мегапікселями за площею та настроюваним лімітом розміру файлу (властивість `МаксимальныйРазмерКартинки`, за замовчуванням 50 МБ). Ліміти перевіряються до виділення пам'яті та до растеризації PDF.
