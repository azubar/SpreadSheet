# Використання компоненти в 1С:Підприємство / BAS

## Підключення з файлу

```bsl
// Windows x64
ПутьКомпоненты = "C:\Компоненты\spreadsheet_x86_64.dll";
// Windows x86 (32-бітний клієнт 1С)
// ПутьКомпоненты = "C:\Компоненты\spreadsheet_i386.dll";
// Linux (сервер)
// ПутьКомпоненты = "/opt/addins/libspreadsheet_x86_64.so";

Если НЕ ПодключитьВнешнююКомпоненту(ПутьКомпоненты, "SS", ТипВнешнейКомпоненты.Native) Тогда
    ВызватьИсключение "Не вдалося підключити компоненту SpreadSheet";
КонецЕсли;

Компонента = Новый ("AddIn.SS.SpreadSheet");
```

## Підключення макетом конфігурації (рекомендовано)

1. Запакуйте `spreadsheet_x86_64.dll`, `spreadsheet_i386.dll`,
   `libspreadsheet_x86_64.so` та `MANIFEST.XML` (з каталогу `manifest/`,
   або візьміть готовий `SpreadSheet.zip` зі сторінки релізів) в один
   ZIP-архів.
2. Створіть у конфігурації двійковий макет (наприклад,
   `ОбщийМакет.КомпонентаSpreadSheet`) і завантажте в нього архів.
3. Підключайте так:

```bsl
Если НЕ ПодключитьВнешнююКомпоненту("ОбщийМакет.КомпонентаSpreadSheet", "SS",
        ТипВнешнейКомпоненты.Native) Тогда
    ВызватьИсключение "Не вдалося підключити компоненту SpreadSheet";
КонецЕсли;
Компонента = Новый ("AddIn.SS.SpreadSheet");
```

Платформа сама обере DLL чи SO відповідно до ОС за `MANIFEST.XML`.

## Конвертація файлу MXL

```bsl
Компонента.Качество = 85;   // якість JPEG, 1–100 (для PNG ігнорується)
Компонента.Масштаб  = 150;  // 150 % від початкового розміру

Компонента.СохранитьКартинку("C:\Данные\накладная.mxl",
                             "C:\Данные\накладная.jpg", "JPEG");

// PNG — без втрат, Качество не впливає
Компонента.СохранитьКартинку("C:\Данные\накладная.mxl",
                             "C:\Данные\накладная.png", "PNG");
```

## Конвертація одразу в ДвоичныеДанные

Якщо картинка потрібна не файлом, а значенням (записати у сховище,
відправити через HTTP, вкласти в лист) — використовуйте
`ПолучитьКартинку`: без тимчасового файлу результату.

```bsl
Компонента.Масштаб = 200;
ДанныеКартинки = Компонента.ПолучитьКартинку("C:\Данные\накладная.mxl", "PNG");
// ДанныеКартинки — ДвоичныеДанные, готові до використання:
// ДанныеКартинки.Записать("...") / ПоместитьВоВременноеХранилище(...)
```

При помилці методи генерують виняток із зрозумілим текстом — обгортайте
виклик у `Попытка … Исключение`, якщо потрібна своя обробка:

```bsl
Попытка
    Компонента.СохранитьКартинку(ПутьMXL, ПутьКартинки, "JPEG");
Исключение
    Сообщить(ОписаниеОшибки());
КонецПопытки;
```

Або вимкніть винятки і перевіряйте результат — текст помилки буде у
властивості `ОписаниеОшибки` компоненти:

```bsl
Компонента.ВызыватьИсключения = Ложь;
Если Не Компонента.СохранитьКартинку(ПутьMXL, ПутьКартинки, "JPEG") Тогда
    Сообщить("Не вдалося сформувати картинку: " + Компонента.ОписаниеОшибки);
КонецЕсли;
```

## Якщо є ТабличныйДокумент, а не файл

Технологія Native API не дозволяє передати об'єкт `ТабличныйДокумент`
у компоненту напряму — параметри методів обмежені примітивними типами.
Тому спочатку збережіть документ у тимчасовий файл MXL:

```bsl
ИмяВрФайла = ПолучитьИмяВременногоФайла("mxl");
ТабДок.Записать(ИмяВрФайла, ТипФайлаТабличногоДокумента.MXL);

Компонента.СохранитьКартинку(ИмяВрФайла, "C:\out.jpg", "JPEG");

УдалитьФайлы(ИмяВрФайла);
```

## Повний приклад: друкована форма → картинка у сховище

```bsl
&НаСервере
Функция ПечатнаяФормаВКартинку(ТабДок)

    Если НЕ ПодключитьВнешнююКомпоненту("ОбщийМакет.КомпонентаSpreadSheet",
            "SS", ТипВнешнейКомпоненты.Native) Тогда
        ВызватьИсключение "Компонента SpreadSheet недоступна";
    КонецЕсли;
    Компонента = Новый ("AddIn.SS.SpreadSheet");
    Компонента.Масштаб = 200; // чіткий текст для перегляду на телефоні

    ФайлMXL  = ПолучитьИмяВременногоФайла("mxl");
    ФайлPNG  = ПолучитьИмяВременногоФайла("png");
    ТабДок.Записать(ФайлMXL, ТипФайлаТабличногоДокумента.MXL);

    Попытка
        Компонента.СохранитьКартинку(ФайлMXL, ФайлPNG, "PNG");
        Результат = Новый ХранимоеЗначение(Новый ДвоичныеДанные(ФайлPNG));
    Исключение
        УдалитьФайлы(ФайлMXL);
        УдалитьФайлы(ФайлPNG);
        ВызватьИсключение;
    КонецПопытки;

    УдалитьФайлы(ФайлMXL);
    УдалитьФайлы(ФайлPNG);
    Возврат Результат;

КонецФункции
```

## Поради

- Для документів із дрібним шрифтом (8 pt) використовуйте
  `Масштаб = 150…200` — картинка буде помітно читабельнішою.
- Для месенджерів зазвичай достатньо `"JPEG"` з `Качество = 80…90`;
  для документів з тонкими лініями кращий `"PNG"`.
- На Linux-сервері жодних додаткових пакетів (шрифтів, X11) не потрібно.
