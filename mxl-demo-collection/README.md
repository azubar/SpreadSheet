# Колекція демонстрацій MXL та опис формату

Цей каталог містить готові бінарні файли табличних документів (`.mxl`), генератори демонстраційних прикладів на Python та документацію щодо структури формату.

---

## 1. Файли MXL у колекції

* **[ДемонстрацияВозможностейТабличногоДокумента.mxl](ДемонстрацияВозможностейТабличногоДокумента.mxl)** — містить 65 кольорів заливки, 65 кольорів тексту, різні начертання шрифтів, вертикальний текст, формати чисел/дат та базові стилі меж.
* **[ДемонстрацияУзоровРисунковБитов15-32.mxl](ДемонстрацияУзоровРисунковБитов15-32.mxl)** — демонстрація 19 видів узорів, вбудованого PNG-зображення, графічних об'єктів (надпис, прямокутник, діаграма) та масок бітів 15-32.
* **[ДемонстрацияГраницОбъединений.mxl](ДемонстрацияГраницОбъединений.mxl)** — окремі межі для кожної сторони комірки, всі можливі товщини та стилі ліній, підкреслення тексту та об'єднані області різного розміру.
* **[ДемонстрацияРазмещенияТекста.mxl](ДемонстрацияРазмещенияТекста.mxl)** — демонстрація чотирьох режимів перенесення та контролю тексту (Авто, Обрезать, Забивать, Переносить) на різних типах комірок та об'єднань.
* **[ДемонстрацияПечатиРазрывов_A4_Книжная.mxl](ДемонстрацияПечатиРазрывов_A4_Книжная.mxl)** — налаштування друку: формат A4, книжна орієнтація.
* **[ДемонстрацияПечатиРазрывов_A4_Альбомная.mxl](ДемонстрацияПечатиРазрывов_A4_Альбомная.mxl)** — налаштування друку: формат A4, альбомна орієнтація.
* **[ДемонстрацияПечатиРазрывов_A3_Книжная.mxl](ДемонстрацияПечатиРазрывов_A3_Книжная.mxl)** — налаштування друку: формат A3, книжна орієнтація.

*Кожен файл друку містить налаштування полів, масштабу, області друку, повторюваних рядків/колонок, відключену сітку, а також два горизонтальні та один вертикальний розриви сторінок.*

### Згенеровані без 1С варіанти (`generated/`)

Скрипт [`tools/mxl_variants.py`](tools/mxl_variants.py) створює варіанти демо друку **без платформи 1С** — читає готовий MXL, змінює параметри друку чи структуру та записує новий файл:

* `Печать_A4_Альбомная_50.mxl`, `Печать_A5_Книжная.mxl`, `Печать_A3_Альбомная_Автомасштаб.mxl`, `Печать_A4_Книжная_Цветная.mxl` — інші формат аркуша, орієнтація, масштаб друку, автомасштаб, кольоровий друк;
* `ДлиннаяТаблица_БезРазрывов.mxl` — 349 рядків без явних розривів та без області друку.

```bash
python mxl-demo-collection/tools/mxl_variants.py
```

Ці файли використовуються в регресійних тестах (`spreadsheet/tests/golden.rs`). Значення параметрів друку взяті з файлів, збережених 1С, але відкриття самих згенерованих файлів у 1С не перевірялося.

## 2. Запуск генерації файлів

Для запуску скриптів генерації потрібен інтерпретатор Python з інстальованим пакетом `pywin32` та доступ до файлової бази 1С/BAS на Windows (через COM-з'єднання):

```powershell
# 1. Генерація загального демо-файлу
python .\generate_mxl_demo.py --base .\base --output .\ДемонстрацияВозможностейТабличногоДокумента.mxl

# 2. Генерація узорів, картинок та бітів
python .\generate_mxl_patterns_drawings_bits_demo.py --base .\base --output .\ДемонстрацияУзоровРисунковБитов15-32.mxl --image .\splash.png

# 3. Генерація меж та об'єднань комірок
python .\generate_mxl_borders_merges_demo.py --base .\base --output .\ДемонстрацияГраницОбъединений.mxl

# 4. Генерація файлів параметрів друку (створить 3 файли)
python .\generate_mxl_printing_demo.py --base .\base --output-dir .

# 5. Генерація демонстрації режимів розміщення тексту
python .\generate_mxl_text_placement_demo.py --base .\base --output .\ДемонстрацияРазмещенияТекста.mxl
```

## 3. Детальний опис структури формату MXL

Файли `.mxl` формуються об'єктом `SpreadsheetDocument` платформи 1С/BAS і зберігаються у вигляді текстової скобочної серіалізації значень (крім заголовка).

### XML-представлення макета
При вивантаженні з конфігуратора макети зберігаються як XML-файли. Типова коренева структура такого XML:

```xml
<document xmlns="http://v8.1c.ru/8.2/data/spreadsheet"
          xmlns:v8="http://v8.1c.ru/8.1/data/core"
          xmlns:v8ui="http://v8.1c.ru/8.1/data/ui">
  <languageSettings><setting languageCode="uk"/></languageSettings>
  <columns>...</columns>
  <rowsItem>...</rowsItem>
  <drawing>...</drawing>
  <templateMode>true</templateMode>
  <defaultFormatIndex>0</defaultFormatIndex>
  <merge>...</merge>
  <namedItem>...</namedItem>
  <line>...</line>
  <font>...</font>
  <format>...</format>
  <picture>...</picture>
</document>
```

### Основні вузли макета
* `columns` — ширини колонок, їх діапазони та посилання на індекси форматів.
* `rowsItem` — рядки, що містять комірки `<c>` із даними.
* `merge` — описує об'єднані прямокутні області комірок (координати починаються з `0`).
* `font` / `line` / `format` — таблиці шрифтів, ліній меж та загальних форматів відображення.
* `drawing` — графічні об'єкти (надписи, малюнки, діаграми).
* `picture` — бінарні дані картинок (вбудовані в документ).

### Специфікація режимів розміщення тексту (TextPlacement)
Перерахування `ТипРазмещенияТекстаТабличногоДокумента` містить 4 режими:
1. **`Авто` (`Auto`)** — текст вільно виходить на сусідні порожні комірки праворуч. Якщо сусідня комірка зайнята — текст обрізається.
2. **`Переносить` (`Wrap`)** — текст автоматично переноситься на наступні рядки в межах ширини комірки.
3. **`Забивать` (`Block`)** — текст циклічно повторюється горизонтально до повного заповнення всієї ширини комірки (корисно для створення ліній заповнення).
4. **`Обрезать` (`Cut`)** — текст строго обрізається по межі комірки без виходу на сусідні.
